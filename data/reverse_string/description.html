Given a string s, return the string with its characters in reverse order. Preserve all characters including spaces and punctuation.

Method Signature

public String reverseString(String s)

Requirements

  • Return a new string with characters in reverse order
  • Preserve all characters, including spaces
  • The input string may be empty

Example

Input:

s = "hello"

Output:

"olleh"

Additional Examples

Example 2:

Input: s = "racecar"
Output: "racecar"

Example 3:

Input: s = "Hello World"
Output: "dlroW olleH"

Notes

  • You may use built-in string utilities
