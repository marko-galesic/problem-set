Return true if the array has a continuous subarray of length at least 2 whose sum is a multiple of k.

Method Signature

public boolean checkSubarraySum(int[] nums, int k)

Requirements

  • The subarray length must be at least 2.
  • If k is 0, treat a sum of 0 as a multiple of k.

Example

Input:

nums = [23, 2, 4, 6, 7], k = 6

Output:

true
