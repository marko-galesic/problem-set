Given a BST and two values, return the value of their lowest common ancestor.

Method Signature

public int lowestCommonAncestorBst(TreeNode root, int p, int q)

Requirements

  • p and q are values in the BST.
  • Return the value of their lowest common ancestor.

Example

Input:

root = [6,2,8,0,4,7,9,null,null,3,5], p = 2, q = 8

Output:

6
