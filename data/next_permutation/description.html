Given an integer array, return the next lexicographically greater permutation. If no such permutation exists, return the smallest permutation (sorted ascending).

Method Signature

public int[] nextPermutation(int[] nums)

Requirements

  • Return the next permutation in lexicographic order
  • If already the last permutation, return the sorted order

Example

Input:

nums = [1, 2, 3]

Output:

[1, 3, 2]
