You are scheduling banner ads during a YouTube video. Each ad is represented by [start, end, payout], where start < end and payout is positive.

Choose a set of non-overlapping ads that maximizes the total payout. The input may be unsorted. Ads that only touch at an endpoint are compatible: an ad ending at time t may be followed by one starting at time t.

Method Signature

public int maxPayout(int[][] ads)

Example

Input:

ads = [[1, 4, 3], [3, 7, 7], [6, 10, 8], [9, 10, 5]]

Output:

12

Constraints

  • Each row contains exactly three integers: [start, end, payout].
  • start < end.
  • payout > 0.
