Implement a function invertTree that inverts a binary tree and returns the root of the inverted tree.

Method Signature

public TreeNode invertTree(TreeNode root)

Requirements

  • Swap the left and right child of every node
  • The TreeNode class is provided as a utility class (see TreeNode.java)
  • If the input tree is empty (null), return null

TreeNode Structure

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;

    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}

Example

Input:

root = [4, 2, 7, 1, 3, 6, 9]

Output:

[4, 7, 2, 9, 6, 3, 1]

Explanation: Each node's left and right children are swapped.

Additional Examples

Example 2:

Input: root = [2, 1, 3]
Output: [2, 3, 1]

Example 3:

Input: root = []
Output: null

Notes

  • The number of nodes is in the range [0, 2000]
  • Node values are in the range [-100, 100]
  • You can use either a recursive or iterative approach
