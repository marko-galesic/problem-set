Implement a function getIntersectionNode that returns the node at which two singly linked lists intersect.

Method Signature

public ListNode getIntersectionNode(ListNode headA, ListNode headB)

Requirements

  • Return the node where the two lists intersect, or null if they do not intersect
  • Intersection is based on reference, not value
  • The ListNode class is provided as a utility class (see ListNode.java)
  • If either input list is empty (null), return null

ListNode Structure

class ListNode {
    int val;
    ListNode next;

    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}

Example

Input:

headA = [4, 1, 8, 4, 5]
headB = [5, 6, 1, 8, 4, 5]

Output:

[8, 4, 5]

Explanation: The two lists share the tail starting at the node with value 8.

Additional Examples

Example 2:

Input: headA = [1, 9, 1, 2, 4], headB = [3, 2, 4]
Output: [2, 4]

Example 3:

Input: headA = [2, 6, 4], headB = [1, 5]
Output: null

Notes

  • The number of nodes in each list is in the range [0, 3 * 10^4]
  • Node values are in the range [-10^5, 10^5]
  • Try to solve it in O(n + m) time and O(1) extra space
