Given a string of digits, where A=1 and Z=26, return the number of ways to decode the string.

Method Signature

public int numDecodings(String s)

Requirements

  • Digits must be decoded into 1- or 2-digit numbers between 1 and 26
  • A leading zero is invalid
  • Return 0 if no valid decoding exists

Example

Input:

s = "226"

Output:

3
