Given a list of product names and a search word, return up to three product suggestions for every prefix of the search word. Suggestions must be in lexicographical order.

Method Signature

public String[][] suggestedProducts(String[] products, String searchWord)

Output Format

  • The result has length equal to searchWord.length()
  • Each row contains up to three products that start with the current prefix
  • Products are sorted lexicographically

Example

products = ["mobile","mouse","moneypot","monitor","mousepad"]
searchWord = "mouse"

Output:
[
  ["mobile","moneypot","monitor"],
  ["mobile","moneypot","monitor"],
  ["mouse","mousepad"],
  ["mouse","mousepad"],
  ["mouse","mousepad"]
]
