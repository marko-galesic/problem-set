Given an integer n, return all strings with n pairs of well-formed parentheses.

Method Signature

public String[] generateParenthesis(int n)

Requirements

  • Each returned string must contain exactly n opening and n closing parentheses
  • Every prefix of the string must have at least as many '(' as ')'
  • Return results in lexicographic order, adding '(' before ')' when branching

Example

Input:

n = 3

Output:

["((()))", "(()())", "(())()", "()(())", "()()()"]

Additional Example

Input: n = 1
Output: ["()"]

Notes

  • If n = 0, return a single empty string: [""]
  • Output order must be deterministic and lexicographic
