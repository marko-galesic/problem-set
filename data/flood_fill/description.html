Perform a flood fill on the image starting from (sr, sc), replacing all connected cells with the starting color by the new color.

Method Signature

public int[][] floodFill(int[][] image, int sr, int sc, int color)

Example

Input:

image = [[1,1,1],[1,1,0],[1,0,1]]
sr = 1
sc = 1
color = 2

Output:

[[2,2,2],[2,2,0],[2,0,1]]
