Given a list of daily temperatures, return an array where each element is the number of days you would have to wait until a warmer temperature. If there is no future day, put 0.

Method Signature

public int[] dailyTemperatures(int[] temperatures)

Example

temperatures = [73,74,75,71,69,72,76,73]
Output: [1,1,4,2,1,1,0,0]
