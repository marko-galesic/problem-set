Matrix Block Sum

Given an m x n integer matrix mat and integer k, return the matrix where each cell is the sum of all elements within k rows and k columns of that cell (bounded by edges).

Example

Input: mat = [[1, 2, 3], [4, 5, 6], [7, 8, 9]], k = 1
Output: [[12, 21, 16], [27, 45, 33], [24, 39, 28]]
