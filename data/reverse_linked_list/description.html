Implement a function reverseList that reverses a singly linked list and returns the new head of the reversed list.

Method Signature

public ListNode reverseList(ListNode head)

Requirements

  • Given the head of a singly linked list, reverse the list and return the reversed list's head
  • The ListNode class is provided as a utility class (see ListNode.java)
  • You should reverse the list in-place if possible, or create a new reversed list
  • If the input list is empty (null), return null
  • If the input list has a single node, return that node

ListNode Structure

class ListNode {
    int val;
    ListNode next;
    
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}

Example

Input:

head = [1, 2, 3, 4, 5]

Output:

[5, 4, 3, 2, 1]

Explanation: The original list 1 -> 2 -> 3 -> 4 -> 5 is reversed to 5 -> 4 -> 3 -> 2 -> 1.

Additional Examples

Example 2:

Input: head = [1, 2]
Output: [2, 1]

Example 3:

Input: head = []
Output: []

Example 4:

Input: head = [1]
Output: [1]

Notes

  • The number of nodes in the list is the range [0, 5000]
  • Node values are in the range [-5000, 5000]
  • You can use either an iterative or recursive approach
  • Try to solve it in O(n) time and O(1) extra space if possible
