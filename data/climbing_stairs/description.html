You are climbing a staircase with n steps. Each time you can climb either 1 or 2 steps. Return the number of distinct ways to reach the top.

Method Signature

public int climbStairs(int n)

Requirements

  • Given n, return the number of distinct sequences of 1-step and 2-step moves
  • Order matters: 1 + 2 and 2 + 1 are different
  • n is a positive integer

Example

Input:

n = 4

Output:

5

Explanation: The five ways are 1+1+1+1, 1+1+2, 1+2+1, 2+1+1, and 2+2.

Additional Examples

Example 2:

Input: n = 1
Output: 1

Example 3:

Input: n = 2
Output: 2

Notes

  • This is the classic Fibonacci-style counting problem
  • An iterative solution with constant extra space is sufficient
