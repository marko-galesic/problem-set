Given a sorted array arr, return the k elements closest to x in ascending order.

Method Signature

public int[] findClosestElements(int[] arr, int k, int x)

Requirements

  • If there is a tie, favor the smaller elements.
  • Return the result in ascending order.

Example

Input:

arr = [1, 2, 3, 4, 5], k = 4, x = 3

Output:

[1, 2, 3, 4]
