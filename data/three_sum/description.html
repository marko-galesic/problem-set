Implement a function threeSum that finds all unique triplets in an integer array that sum to zero.

Method Signature

public int[][] threeSum(int[] nums)

Requirements

  • Return all unique triplets [a, b, c] such that a + b + c = 0
  • Each triplet must be sorted in ascending order
  • The list of triplets must be sorted lexicographically (by first, then second, then third)
  • No duplicate triplets are allowed

Example

Input:

nums = [-1, 0, 1, 2, -1, -4]

Output:

[[-1, -1, 2], [-1, 0, 1]]

Explanation: The triplets [-1, -1, 2] and [-1, 0, 1] sum to zero. Each triplet is sorted, and the list is sorted lexicographically.

Additional Examples

Example 2:

Input: nums = [0, 0, 0, 0]
Output: [[0, 0, 0]]

Example 3:

Input: nums = [0, 1, 1]
Output: []

Notes

  • The input array may contain negative numbers and duplicates
  • Return an empty list if no valid triplets exist
