Given an array of points points, return the k closest points to the origin (0,0). Order points by distance, breaking ties by x then y.

Method Signature

public int[][] kClosest(int[][] points, int k)

Requirements

  • Distance is Euclidean (use squared distance)
  • If distances tie, sort by x then y
  • Return the first k points after ordering

Example

Input:

points = [[1, 3], [-2, 2]], k = 1

Output:

[[-2, 2]]
