Implement a function isValidBST that determines whether a binary tree is a valid binary search tree (BST).

Method Signature

public boolean isValidBST(TreeNode root)

Requirements

  • A valid BST satisfies: all values in the left subtree are strictly less than the node's value
  • All values in the right subtree are strictly greater than the node's value
  • Both left and right subtrees must also be valid BSTs
  • Duplicate values are not allowed in a valid BST
  • The TreeNode class is provided as a utility class (see TreeNode.java)
  • If the input tree is empty (null), return true

TreeNode Structure

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;

    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}

Example

Input:

root = [2, 1, 3]

Output:

true

Explanation: The left value (1) is less than 2 and the right value (3) is greater than 2.

Additional Examples

Example 2:

Input: root = [5, 1, 4, null, null, 3, 6]
Output: false

Example 3:

Input: root = []
Output: true

Notes

  • The number of nodes is in the range [0, 10^4]
  • Node values are in the range [-2^31, 2^31 - 1]
  • Use strict inequalities for BST validation
