Given the cost array where cost[i] is the cost of step i, return the minimum cost to reach the top.

Method Signature

public int minCostClimbingStairs(int[] cost)

Requirements

  • You can start from step 0 or step 1.
  • You can climb either 1 or 2 steps at a time.

Example

Input:

cost = [10, 15, 20]

Output:

15
