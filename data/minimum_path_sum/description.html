Given a grid of non-negative integers, find a path from the top-left to the bottom-right with the minimum sum, moving only right or down.

Method Signature

public int minPathSum(int[][] grid)

Requirements

  • You may only move right or down
  • Return the minimum possible sum along a valid path

Example

Input:

grid = [[1, 3, 1], [1, 5, 1], [4, 2, 1]]

Output:

7
