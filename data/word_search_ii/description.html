Given a 2D board of letters and a list of words, return all words that can be formed by sequentially adjacent cells (up, down, left, right). A cell may not be used more than once in a word.

Method Signature

public String[] findWords(char[][] board, String[] words)

Return Value

  • Return the found words in lexicographical order
  • Each word should appear at most once in the output

Example

board = [
  ['o','a','a','n'],
  ['e','t','a','e'],
  ['i','h','k','r'],
  ['i','f','l','v']
]
words = ["oath","pea","eat","rain"]

Output: ["eat","oath"]
