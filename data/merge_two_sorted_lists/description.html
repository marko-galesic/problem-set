Implement a function mergeTwoLists that merges two sorted linked lists into one sorted linked list and returns the head of the merged list.

Method Signature

public ListNode mergeTwoLists(ListNode list1, ListNode list2)

Requirements

  • Given the heads of two sorted linked lists, merge them into one sorted list
  • The merged list should be made by splicing together the nodes of the first two lists
  • The ListNode class is provided as a utility class (see ListNode.java)
  • If either list is empty (null), return the other list
  • If both lists are empty, return null
  • The merged list should maintain the sorted order

ListNode Structure

class ListNode {
    int val;
    ListNode next;
    
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}

Example

Input:

list1 = [1, 2, 4]
list2 = [1, 3, 4]

Output:

[1, 1, 2, 3, 4, 4]

Explanation: The lists 1 -> 2 -> 4 and 1 -> 3 -> 4 are merged into 1 -> 1 -> 2 -> 3 -> 4 -> 4.

Additional Examples

Example 2:

Input: list1 = [], list2 = []
Output: []

Example 3:

Input: list1 = [], list2 = [0]
Output: [0]

Example 4:

Input: list1 = [1, 3, 5], list2 = [2, 4, 6]
Output: [1, 2, 3, 4, 5, 6]

Notes

  • The number of nodes in both lists is in the range [0, 50]
  • Node values are in the range [-100, 100]
  • Both list1 and list2 are sorted in non-decreasing order
  • You can use either an iterative or recursive approach
  • Try to solve it in O(n + m) time and O(1) extra space if possible
