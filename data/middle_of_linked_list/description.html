Implement a function middleNode that returns the middle node of a singly linked list. If the list has an even number of nodes, return the second middle node.

Method Signature

public ListNode middleNode(ListNode head)

Requirements

  • Return the middle node of the list (second middle when length is even)
  • The ListNode class is provided as a utility class (see ListNode.java)
  • If the input list is empty (null), return null

ListNode Structure

class ListNode {
    int val;
    ListNode next;
    
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}

Example

Input:

head = [1, 2, 3, 4, 5]

Output:

[3, 4, 5]

Explanation: The middle node is 3, so the returned list is 3 -> 4 -> 5.

Additional Examples

Example 2:

Input: head = [1, 2, 3, 4, 5, 6]
Output: [4, 5, 6]

Example 3:

Input: head = [1]
Output: [1]

Example 4:

Input: head = []
Output: []

Notes

  • The number of nodes is in the range [0, 100]
  • Node values are in the range [-10^4, 10^4]
  • Try to solve it in O(n) time and O(1) extra space
