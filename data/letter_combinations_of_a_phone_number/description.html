Implement a function letterCombinations that returns all possible letter combinations a phone number could represent.

Method Signature

public String[] letterCombinations(String digits)

Requirements

  • Use the digit mapping: 2: abc, 3: def, 4: ghi, 5: jkl, 6: mno, 7: pqrs, 8: tuv, 9: wxyz
  • Return combinations in lexicographic order based on the mapping and digit order
  • If digits is empty, return an empty list

Example

Input:

digits = "23"

Output:

["ad", "ae", "af", "bd", "be", "bf", "cd", "ce", "cf"]

Explanation: Combine each letter for 2 (abc) with each letter for 3 (def).

Additional Examples

Example 2:

Input: digits = ""
Output: []

Example 3:

Input: digits = "7"
Output: ["p", "q", "r", "s"]
