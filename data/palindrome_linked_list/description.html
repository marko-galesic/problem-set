Given the head of a singly linked list, return true if the list is a palindrome and false otherwise.

Method Signature

public boolean isPalindrome(ListNode head)

Requirements

  • Compare values from both ends of the list
  • The ListNode class is provided as a utility class (see ListNode.java)
  • Return true for an empty list or a single node
  • Try to solve it in O(n) time and O(1) extra space if possible

ListNode Structure

class ListNode {
    int val;
    ListNode next;

    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}

Example

Input:

head = [1, 2, 2, 1]

Output:

true

Explanation: The list 1 -> 2 -> 2 -> 1 reads the same forward and backward.

Additional Examples

Example 2:

Input: head = [1, 2]
Output: false

Example 3:

Input: head = [1]
Output: true

Example 4:

Input: head = []
Output: true

Notes

  • The number of nodes in the list is in the range [0, 10^5]
  • Node values are in the range [-10^9, 10^9]
