Group strings that can be shifted to each other by the same amount (e.g., "abc" -> "bcd").

Method Signature

public String[][] groupShiftedStrings(String[] strings)

Requirements

  • Strings belong to the same group if they share the same shift pattern.
  • Sort each group in ascending lexicographic order.
  • Sort the list of groups by the first string in each group.

Example

Input:

strings = ["abc", "bcd", "acef", "xyz", "az", "ba", "a", "z"]

Output:

[["a", "z"], ["abc", "bcd", "xyz"], ["acef"], ["az", "ba"]]
