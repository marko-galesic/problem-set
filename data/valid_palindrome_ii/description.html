Given a string s, return true if it can be a palindrome after deleting at most one character.

Method Signature

public boolean validPalindrome(String s)

Requirements

  • You may delete at most one character
  • Do not reorder the remaining characters
  • Return true if a palindrome is possible

Example

Input:

s = "abca"

Output:

true

Additional Examples

Example 2:

Input: s = "aba"
Output: true

Example 3:

Input: s = "abc"
Output: false

Notes

  • The empty string is a palindrome
  • Strings may contain lowercase letters only
