You have a 4-wheel lock starting at "0000". Each move turns one wheel up or down by one. Return the minimum number of moves to reach the target without entering any deadend states, or -1 if impossible.

Method Signature

public int openLock(String[] deadends, String target)

Requirements

  • Each move changes exactly one digit by +1 or -1 with wraparound.
  • You may not visit any deadend combination.
  • Return -1 if the target cannot be reached.

Example

Input:

deadends = ["0201","0101","0102","1212","2002"], target = "0202"

Output:

6
