In a maze with 0 as open and 1 as wall, a move rolls the ball in one direction until it hits a wall. Return the minimum number of rolls to reach the destination.

Method Signature

public int shortestDistance(int[][] maze, int[] start, int[] destination)

Requirements

  • Each roll counts as one move regardless of distance.
  • You may move only in four directions.
  • Return -1 if the destination cannot be reached.

Example

Input:

maze = [[0,0,0],[0,1,0],[0,0,0]], start = [0,0], destination = [2,2]

Output:

2
