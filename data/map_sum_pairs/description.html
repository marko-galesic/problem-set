Implement a map that supports inserting key-value pairs and returning the sum of all values whose keys start with a given prefix.

Method Signature

public int[] mapSumOps(String[] ops, String[] keys, int[] vals)

Operation Format

  • ops[i] is one of: "insert", "sum"
  • keys[i] is the key (for insert) or prefix (for sum)
  • vals[i] is the value for insert; it is ignored for sum

Return Value

  • Return an array of results for sum operations only

Example

ops  = ["insert","insert","sum","insert","sum"]
keys = ["apple","app","ap","app","ap"]
vals = [3,2,0,5,0]

Output: [5,8]
