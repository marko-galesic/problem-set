Given a list of non-overlapping intervals sorted by start time, insert a new interval and merge any overlaps. Return the resulting list of intervals sorted by start.

Method Signature

public int[][] insert(int[][] intervals, int[] newInterval)

Requirements

  • Intervals are sorted in ascending order and non-overlapping.
  • Insert newInterval into the list and merge any overlapping intervals.
  • Return the merged list of intervals sorted by start time.
  • If the input list is empty, return a list containing only newInterval.

Example

Input:

intervals = [[1, 3], [6, 9]]
newInterval = [2, 5]

Output:

[[1, 5], [6, 9]]

Explanation: The new interval overlaps the first interval, so they are merged.
