Given a 9 x 9 Sudoku board, fill the empty cells so that each row, column, and 3 x 3 subgrid contains the digits '1' through '9' exactly once. Empty cells are marked with '.'.

Method Signature

public char[][] solveSudoku(char[][] board)

Requirements

  • Replace every '.' with a digit '1' to '9'
  • Each row, column, and 3 x 3 subgrid must contain every digit exactly once
  • Return the completed board
  • You may assume the input has at least one valid solution

Example

Input:

board = [
  ['5','3','.','.','7','.','.','.','.'],
  ['6','.','.','1','9','5','.','.','.'],
  ['.','9','8','.','.','.','.','6','.'],
  ['8','.','.','.','6','.','.','.','3'],
  ['4','.','.','8','.','3','.','.','1'],
  ['7','.','.','.','2','.','.','.','6'],
  ['.','6','.','.','.','.','2','8','.'],
  ['.','.','.','4','1','9','.','.','5'],
  ['.','.','.','.','8','.','.','7','9']
]

Output:

[
  ['5','3','4','6','7','8','9','1','2'],
  ['6','7','2','1','9','5','3','4','8'],
  ['1','9','8','3','4','2','5','6','7'],
  ['8','5','9','7','6','1','4','2','3'],
  ['4','2','6','8','5','3','7','9','1'],
  ['7','1','3','9','2','4','8','5','6'],
  ['9','6','1','5','3','7','2','8','4'],
  ['2','8','7','4','1','9','6','3','5'],
  ['3','4','5','2','8','6','1','7','9']
]
