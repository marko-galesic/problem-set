Given a binary array nums containing only 0 and 1, return the maximum length of a contiguous subarray with an equal number of 0 and 1.

Method Signature

public int findMaxLength(int[] nums)

Requirements

  • Return the length of the longest valid subarray
  • Return 0 if no valid subarray exists
  • The input contains only 0 and 1

Example

Input:

nums = [0, 1, 0, 1]

Output:

4
