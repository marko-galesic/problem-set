Implement a function subsetsWithDup that returns all unique subsets of an integer array that may contain duplicates.

Method Signature

public int[][] subsetsWithDup(int[] nums)

Requirements

  • Return all distinct subsets (the power set) of nums
  • Each subset must be in nondecreasing order
  • The list of subsets must be sorted lexicographically by elements
  • If one subset is a prefix of another, the shorter subset comes first

Example

Input:

nums = [1, 2, 2]

Output:

[[], [1], [1, 2], [1, 2, 2], [2], [2, 2]]

Additional Example

Input:

nums = []

Output:

[[]]

Notes

  • The input array may contain duplicates
  • The empty subset must be included
