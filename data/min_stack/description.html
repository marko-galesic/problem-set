Process a sequence of stack operations (push, pop, top, getMin) and return the outputs for each top/getMin call in order. Use -1 when the stack is empty.

Method Signature

public int[] minStackOps(String[] ops, int[][] values)

Example

Input:

ops = ["push", "push", "getMin", "top"]
values = [[2], [1], [], []]

Output:

[1, 1]

Notes

  • Each operation in ops aligns with the argument list in values.
  • For push, values[i] contains a single value. For pop/top/getMin, values[i] is empty.
  • Return outputs only for top and getMin operations.
