Return "IPv4", "IPv6", or "Neither" depending on whether queryIP is a valid IP address.

Method Signature

public String validIPAddress(String queryIP)

Requirements

  • IPv4 must have 4 decimal parts between 0 and 255.
  • IPv6 must have 8 groups of 1-4 hex digits.

Example

Input:

queryIP = "172.16.254.1"

Output:

"IPv4"
