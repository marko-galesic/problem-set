Given two strings s and t, return true if s is a subsequence of t, or false otherwise. A subsequence preserves order but does not need to be contiguous.

Method Signature

public boolean isSubsequence(String s, String t)

Requirements

  • Return true if you can delete some characters from t to get s
  • Return false otherwise
  • The comparison is case-sensitive
  • An empty s is always a subsequence of t

Example

Input:

s = "abc", t = "ahbgdc"

Output:

true

Additional Examples

Example 2:

Input: s = "axc", t = "ahbgdc"
Output: false

Example 3:

Input: s = "", t = "anything"
Output: true
