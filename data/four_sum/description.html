Given an integer array nums and an integer target, return all unique quadruplets [a, b, c, d] such that a + b + c + d == target.

Method Signature

public int[][] fourSum(int[] nums, int target)

Requirements

  • Each quadruplet must contain four numbers from nums
  • Each quadruplet must be sorted in non-decreasing order
  • The list of quadruplets must be sorted lexicographically (by first, then second, then third, then fourth)
  • No duplicate quadruplets are allowed
  • If there are fewer than four numbers or no valid quadruplets, return an empty list

Example

Input:

nums = [1, 0, -1, 0, -2, 2]
target = 0

Output:

[[-2, -1, 1, 2], [-2, 0, 0, 2], [-1, 0, 0, 1]]

Explanation: The quadruplets are unique, sorted internally, and ordered lexicographically.

Notes

  • The array may contain negative numbers and duplicates
  • Return an empty list when no quadruplets match the target
