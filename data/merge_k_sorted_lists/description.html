Given k sorted integer arrays, merge them into one sorted array.

Method Signature

public int[] mergeKSortedLists(int[][] lists)

Requirements

  • Each list is sorted in ascending order.
  • Return a single sorted array.

Example

Input:

lists = [[1,4,5],[1,3,4],[2,6]]

Output:

[1, 1, 2, 3, 4, 4, 5, 6]
