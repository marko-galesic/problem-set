You are given an n x n matrix. Rotate the matrix 90 degrees clockwise and return the rotated matrix.

Method Signature

public int[][] rotate(int[][] matrix)

Requirements

  • The input is a square matrix
  • Return the rotated matrix in clockwise order

Example

Input:

matrix = [[1,2,3],[4,5,6],[7,8,9]]

Output:

[[7,4,1],[8,5,2],[9,6,3]]

Additional Example

Input:

matrix = [[1,2],[3,4]]

Output:

[[3,1],[4,2]]
