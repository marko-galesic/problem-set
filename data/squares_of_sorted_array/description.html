Given a sorted array of integers nums (sorted in non-decreasing order), return an array of the squares of each number, also sorted in non-decreasing order.

Method Signature

public int[] sortedSquares(int[] nums)

Requirements

  • Return a new array containing the squared values in non-decreasing order.

Example

Input:

nums = [-4, -1, 0, 3, 10]

Output:

[0, 1, 9, 16, 100]
