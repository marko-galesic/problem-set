Given an array of positive integers nums and an integer k, return the number of contiguous subarrays where the product is less than k.

Method Signature

public int numSubarrayProductLessThanK(int[] nums, int k)

Requirements

  • Subarray must be contiguous
  • Return 0 when k <= 1

Example

Input:

nums = [10, 5, 2, 6], k = 100

Output:

8
