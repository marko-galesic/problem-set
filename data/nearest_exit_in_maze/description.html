Given a maze of "+" walls and "." open cells, return the minimum number of steps from the entrance to the nearest exit. An exit is any open boundary cell that is not the entrance itself.

Method Signature

public int nearestExit(char[][] maze, int[] entrance)

Requirements

  • Move only up, down, left, or right.
  • The entrance cell does not count as an exit.
  • Return -1 if no exit is reachable.

Example

Input:

maze = [["+","+",".","+"],[".",".",".","+"],["+","+","+","."]], entrance = [1,2]

Output:

1
