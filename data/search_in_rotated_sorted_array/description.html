Given a rotated sorted array of distinct integers nums and an integer target, return the index of target in nums. If the target is not present, return -1.

Method Signature

public int search(int[] nums, int target)

Requirements

  • nums is sorted in ascending order and then rotated at an unknown pivot
  • All values in nums are distinct
  • Return the index of the target, or -1 if not found
  • Use a logarithmic-time search if possible

Example 1

Input:

nums = [4, 5, 6, 7, 0, 1, 2], target = 0

Output:

4

Example 2

Input:

nums = [4, 5, 6, 7, 0, 1, 2], target = 3

Output:

-1

Example 3

Input:

nums = [1, 2, 3, 4, 5], target = 2

Output:

1

Notes

  • The array may be empty
  • All values fit in 32-bit signed integers
