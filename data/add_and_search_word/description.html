Design a word dictionary that supports adding words and searching with a wildcard.

Method Signature

public int[] wordDictionaryOps(String[] ops, String[] words)

Operation Format

  • ops[i] is one of: "add", "search"
  • words[i] is the word or search pattern
  • The search pattern may include '.' which matches any single letter

Return Value

  • Return an array of results for search operations only
  • Use 1 for true and 0 for false

Example

ops  = ["add","add","add","search","search","search"]
words = ["bad","dad","mad","pad","bad",".ad"]

Output: [0,1,1]

Notes

  • All words consist of lowercase English letters
  • The dictionary starts empty
