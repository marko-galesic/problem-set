You are given an m x n matrix where each row is sorted ascending and the first element of each row is greater than the last element of the previous row. Return whether the target exists in the matrix.

Method Signature

public boolean searchMatrix(int[][] matrix, int target)

Example

Input:

matrix = [[1, 3, 5, 7], [10, 11, 16, 20], [23, 30, 34, 60]]
target = 3

Output:

true
