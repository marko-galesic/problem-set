Implement a function topKFrequent that returns the k most frequent elements in an array.

Method Signature

public int[] topKFrequent(int[] nums, int k)

Requirements

  • Return the k most frequent elements from nums
  • Elements should be ordered by descending frequency
  • If multiple elements have the same frequency, you may return them in any order
  • All returned elements must be distinct

Constraints

  • 1 <= nums.length <= 100000
  • -10000 <= nums[i] <= 10000
  • 1 <= k <= number of unique elements in nums

Example

Input:

nums = [1, 1, 1, 2, 2, 3]
k = 2

Output:

[1, 2]

Explanation: The element 1 appears 3 times and 2 appears 2 times, which are the two highest frequencies.

Additional Example

Input: nums = [4, 4, 4, 6, 6, 7], k = 2
Output: [4, 6]
