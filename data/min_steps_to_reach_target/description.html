Starting from a number, you can move to x-1, x+1, or x*2. Return the minimum number of steps to reach the target.

Method Signature

public int minStepsToReachTarget(int start, int target)

Requirements

  • All values are non-negative integers.
  • You may not visit numbers outside the search bounds.
  • Return -1 if the target cannot be reached.

Example

Input:

start = 2, target = 7

Output:

3
