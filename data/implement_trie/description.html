Implement a prefix tree (Trie) that supports insert and prefix queries.

Method Signature

public int[] trieOps(String[] ops, String[] words)

Operation Format

  • ops[i] is one of: "insert", "search", "startsWith"
  • words[i] is the word or prefix for that operation

Return Value

  • Return an array of results for search and startsWith operations only
  • Use 1 for true and 0 for false
  • Results must appear in the same order as the query operations

Example

ops  = ["insert","insert","search","search","startsWith"]
words = ["apple","app","app","ap","app"]

Output: [1,0,1]

Notes

  • All words consist of lowercase English letters
  • The trie starts empty
