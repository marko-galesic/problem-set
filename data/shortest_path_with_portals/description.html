Given a grid with start S, end E, walls #, open cells ., and portal letters a-z, return the minimum steps from S to E using portals.

Method Signature

public int shortestPathWithPortals(char[][] grid)

Requirements

  • Move only up, down, left, or right.
  • Stepping onto a portal letter instantly teleports to its matching letter.
  • Return -1 if the end is unreachable.

Example

Input:

grid = [["S",".","a"],["#","#","."],["a",".","E"]]

Output:

4
