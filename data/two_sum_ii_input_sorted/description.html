Implement a function twoSum that finds two numbers in a sorted array that add up to a target value and returns their 1-based indices.

Method Signature

public int[] twoSum(int[] numbers, int target)

Requirements

  • The input array numbers is sorted in ascending order
  • Return a 1-based index array [i, j] with i < j
  • numbers[i - 1] + numbers[j - 1] == target
  • Each input has exactly one solution and you may not use the same element twice

Example

Input:

numbers = [2, 7, 11, 15]
target = 9

Output:

[1, 2]

Explanation: Because numbers[0] + numbers[1] = 2 + 7 = 9, we return [1, 2].

Additional Examples

Example 2:

Input: numbers = [2, 3, 4], target = 6
Output: [1, 3]

Example 3:

Input: numbers = [-1, 0], target = -1
Output: [1, 2]

Notes

  • Indices are 1-based
  • The array may contain negative numbers and duplicate values
