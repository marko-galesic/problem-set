You are given an array of intervals where intervals[i] = [start, end]. Return the minimum number of intervals you must remove so the remaining intervals are non-overlapping.

Two intervals [a, b] and [c, d] do not overlap if b <= c or d <= a. Intervals that only touch at an endpoint are considered non-overlapping.

Method Signature

public int eraseOverlapIntervals(int[][] intervals)

Requirements

  • Return the minimum number of intervals to remove
  • Intervals may be unsorted
  • If there are 0 or 1 intervals, return 0
  • Intervals that share an endpoint are allowed

Example 1

Input:

intervals = [[1,2],[2,3],[3,4],[1,3]]

Output:

1

Explanation: Remove [1,3] to keep the others non-overlapping.

Example 2

Input:

intervals = [[1,2],[1,2],[1,2]]

Output:

2

Explanation: Only one interval can remain.

Example 3

Input:

intervals = [[1,2],[2,3],[3,4]]

Output:

0

Explanation: The intervals already do not overlap.

Notes

  • 1 <= intervals.length <= 105
  • Each interval has exactly two integers: start and end
  • -105 <= start < end <= 105
