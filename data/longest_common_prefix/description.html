Given an array of strings strs, return the longest common prefix shared by all strings. If there is no common prefix, return an empty string.

Method Signature

public String longestCommonPrefix(String[] strs)

Requirements

  • Return the longest prefix that appears at the start of every string
  • If no common prefix exists, return an empty string
  • If the input array is empty, return an empty string

Example

Input:

strs = ["flower", "flow", "flight"]

Output:

"fl"

Additional Examples

Example 2:

Input: strs = ["dog", "racecar", "car"]
Output: ""

Example 3:

Input: strs = ["prefix"]
Output: "prefix"

Notes

  • Strings may be empty
  • You may use built-in string operations
