Given a string s, partition it into as many parts as possible so that each letter appears in at most one part. Return a list of the partition lengths.

Method Signature

public int[] partitionLabels(String s)

Requirements

  • Each letter appears in at most one part
  • Return lengths of the partitions in order

Example

Input:

s = "ababcbacadefegdehijhklij"

Output:

[9, 7, 8]
