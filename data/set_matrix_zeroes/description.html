Given an m x n integer matrix matrix, if an element is 0, set its entire row and column to 0. Return the resulting matrix.

Method Signature

public int[][] setZeroes(int[][] matrix)

Requirements

  • Use the original matrix values to decide which rows and columns become zero
  • Return the updated matrix
  • Handle empty matrices

Example

Input:

matrix = [[1,1,1],[1,0,1],[1,1,1]]

Output:

[[1,0,1],[0,0,0],[1,0,1]]

Additional Example

Input:

matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]

Output:

[[0,0,0,0],[0,4,5,0],[0,3,1,0]]

Notes

  • You may modify the input matrix in place as long as you return it
