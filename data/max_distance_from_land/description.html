Given a grid of 0s (water) and 1s (land), return the maximum distance from any water cell to the nearest land cell.

Method Signature

public int maxDistance(int[][] grid)

Requirements

  • Move only up, down, left, or right.
  • Return -1 if there is no water or no land.
  • Distance is measured in steps.

Example

Input:

grid = [[1,0,1],[0,0,0],[1,0,1]]

Output:

2
