Given an integer array nums, move all 0 values to the end while maintaining the relative order of the non-zero elements.

Method Signature

public int[] moveZeroes(int[] nums)

Requirements

  • Return an array of the same length as nums
  • All non-zero elements keep their original order
  • All zeros appear at the end of the array

Example

Input:

nums = [0, 1, 0, 3, 12]

Output:

[1, 3, 12, 0, 0]

Explanation: The non-zero values [1, 3, 12] keep their order and zeros move to the end.

Notes

  • The array may contain only zeros or no zeros
  • Negative numbers are allowed
