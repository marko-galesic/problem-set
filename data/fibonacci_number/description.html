Given a non-negative integer n, return the nth Fibonacci number. The sequence is defined as F(0) = 0, F(1) = 1, and F(n) = F(n - 1) + F(n - 2) for n >= 2.

Method Signature

public int fib(int n)

Requirements

  • n >= 0
  • Return the Fibonacci value as an integer

Example 1

Input:

n = 5

Output:

5

Example 2

Input:

n = 10

Output:

55
