Given an array of non-negative integers height where each element represents a bar of width 1, compute how much water can be trapped after raining.

Method Signature

public int trap(int[] height)

Requirements

  • Return the total units of trapped water between bars
  • If no water can be trapped, return 0
  • The input array may be empty

Example 1

Input:

height = [0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]

Output:

6

Explanation: The bars trap a total of 6 units of water.

Example 2

Input:

height = [4, 2, 0, 3, 2, 5]

Output:

9

Example 3

Input:

height = [1, 2, 3, 4]

Output:

0
