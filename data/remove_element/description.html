Given an integer array nums and an integer value val, remove all instances of val in-place and return the number of elements not equal to val.

The relative order of the remaining elements may change. It does not matter what values are left beyond the returned count.

Method Signature

public int removeElement(int[] nums, int val)

Requirements

  • Modify the input array in-place
  • Return the count of elements not equal to val
  • Array order does not need to be preserved

Example 1

Input:

nums = [3, 2, 2, 3], val = 3

Output:

2

Explanation: The remaining elements can be [2, 2] in any order.

Example 2

Input:

nums = [0, 1, 2, 2, 3, 0, 4, 2], val = 2

Output:

5

Explanation: The remaining elements can be [0, 1, 3, 0, 4] in any order.

Notes

  • The array may be empty
  • Values can be negative or repeated
