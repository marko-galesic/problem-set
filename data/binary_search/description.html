Given a sorted integer array nums (ascending) and an integer target, return the index of target in nums. If the target is not present, return -1.

Method Signature

public int binarySearch(int[] nums, int target)

Requirements

  • The input array is sorted in ascending order
  • Return the index of the target, or -1 if not found
  • Use a logarithmic-time search if possible

Example 1

Input:

nums = [-1, 0, 3, 5, 9, 12], target = 9

Output:

4

Example 2

Input:

nums = [-1, 0, 3, 5, 9, 12], target = 2

Output:

-1

Notes

  • The array may be empty
  • All values fit in 32-bit signed integers
