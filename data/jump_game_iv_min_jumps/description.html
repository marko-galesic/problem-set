From index 0, you can move to adjacent indices or any other index with the same value. Return the minimum jumps to reach the last index.

Method Signature

public int minJumps(int[] arr)

Requirements

  • You may jump to i-1, i+1, or any j where arr[j] == arr[i].
  • Return 0 if the array has length 1.
  • Return -1 if the last index is unreachable.

Example

Input:

arr = [100,-23,-23,404,100,23,23,23,3,404]

Output:

3
