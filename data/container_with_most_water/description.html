You are given an array height where height[i] represents the height of a vertical line at position i.

Choose two lines that together with the x-axis form a container. Return the maximum amount of water the container can store.

Method Signature

public int maxArea(int[] height)

Requirements

  • Choose two indices i < j to form the container
  • The area is min(height[i], height[j]) * (j - i)
  • Return the maximum possible area
  • If the array has fewer than two elements, return 0

Example 1

Input:

height = [1, 8, 6, 2, 5, 4, 8, 3, 7]

Output:

49

Explanation: The container formed by lines at indices 1 and 8 has width 7 and height 7, so area = 49.

Example 2

Input:

height = [1, 1]

Output:

1

Example 3

Input:

height = [4, 3, 2, 1, 4]

Output:

16
