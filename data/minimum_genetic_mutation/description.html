Given start and end genes and a bank of valid genes, return the minimum number of mutations to reach the end gene by changing one character at a time.

Method Signature

public int minMutation(String start, String end, String[] bank)

Requirements

  • Each mutation changes exactly one character.
  • Every intermediate gene must be in the bank.
  • Return -1 if the end gene is unreachable.

Example

Input:

start = "AACCGGTT", end = "AACCGGTA", bank = ["AACCGGTA"]

Output:

1
