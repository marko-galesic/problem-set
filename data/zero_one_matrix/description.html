Given a binary matrix, return a matrix where each cell contains the distance to the nearest 0.

Method Signature

public int[][] updateMatrix(int[][] mat)

Requirements

  • Distance is measured in Manhattan steps.
  • Move only up, down, left, or right.
  • Return a matrix of the same size.

Example

Input:

mat = [[0,0,0],[0,1,0],[1,1,1]]

Output:

[[0, 0, 0], [0, 1, 0], [1, 2, 1]]
