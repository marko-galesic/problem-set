Implement a function merge that merges overlapping intervals.

Method Signature

public int[][] merge(int[][] intervals)

Requirements

  • Each interval is inclusive: [start, end]
  • Input may be unsorted
  • Merge intervals that overlap or touch at endpoints
  • Return intervals sorted by start ascending

Example

Input:

intervals = [[1,3],[2,6],[8,10],[15,18]]

Output:

[[1,6],[8,10],[15,18]]

Explanation: [1,3] and [2,6] overlap, so they merge into [1,6].

Additional Example

Input:

intervals = [[1,4],[4,5]]

Output:

[[1,5]]

Notes

  • Return an empty list when the input is empty
