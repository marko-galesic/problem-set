You are given a list of words and a stream of query characters. After each query character is appended to the stream, determine whether any word is a suffix of the current stream.

Method Signature

public int[] streamQueries(String[] words, String[] queries)

Input Format

  • words contains the dictionary words
  • queries contains single-character strings to append to the stream

Return Value

  • Return 1 if any word is a suffix after the query, otherwise 0

Example

words = ["cd","f","kl"]
queries = ["a","b","c","d","e","f"]

Output: [0,0,0,1,0,1]
