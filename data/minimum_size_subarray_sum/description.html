Given an array of positive integers nums and a target sum, return the minimal length of a contiguous subarray with sum at least the target. Return 0 if no such subarray exists.

Method Signature

public int minSubArrayLen(int target, int[] nums)

Requirements

  • Subarray must be contiguous
  • Return 0 when no subarray meets the target

Example

Input:

target = 7, nums = [2, 3, 1, 2, 4, 3]

Output:

2
