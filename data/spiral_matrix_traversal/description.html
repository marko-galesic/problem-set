Return all elements of a matrix in clockwise spiral order.

Method Signature

public int[] spiralMatrixTraversal(int[][] matrix)

Requirements

  • Start at the top-left and move clockwise.
  • Return an empty array for an empty matrix.

Example

Input:

matrix = [[1,2,3],[4,5,6],[7,8,9]]

Output:

[1, 2, 3, 6, 9, 8, 7, 4, 5]
