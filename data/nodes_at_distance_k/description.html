Return all nodes at exact distance k from the start node in an undirected graph.

Method Signature

public int[] nodesAtDistanceK(int n, int[][] edges, int start, int k)

Requirements

  • Nodes are labeled 0..n-1.
  • Return nodes sorted ascending.
  • Return an empty list if none exist.

Example

Input:

n = 6, edges = [[0,1],[0,2],[1,3],[2,4],[4,5]], start = 0, k = 2

Output:

[3, 4]
