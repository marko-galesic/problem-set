Implement a function groupAnagrams that groups strings that are anagrams of each other.

Method Signature

public String[][] groupAnagrams(String[] strs)

Requirements

  • Strings that are anagrams must appear in the same group.
  • Sort each group lexicographically.
  • Sort the list of groups lexicographically by their string lists.

Example

Input:

strs = ["eat", "tea", "tan", "ate", "nat", "bat"]

Output:

[["ate", "eat", "tea"], ["bat"], ["nat", "tan"]]

Additional Example

Input:

strs = ["ab", "ba", "ab", "abc", "bca", "cab"]

Output:

[["ab", "ab", "ba"], ["abc", "bca", "cab"]]
