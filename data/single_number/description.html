Implement a function singleNumber that returns the element that appears exactly once in an integer array.

Method Signature

public int singleNumber(int[] nums)

Requirements

  • Every element appears twice except for one
  • Return the element that appears once

Example

Input:

nums = [2, 2, 1]

Output:

1

Explanation: The value 1 appears once.

Additional Examples

Example 2:

Input: nums = [4, 1, 2, 1, 2]
Output: 4

Example 3:

Input: nums = [-1, -1, -2]
Output: -2

Notes

  • The array contains at least one element
  • Values may be negative
