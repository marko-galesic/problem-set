Given an array and integer k, return the maximum sum of any contiguous subarray of length k.

Method Signature

public int maximumSubarraySumK(int[] nums, int k)

Requirements

  • Use a contiguous subarray of length k.
  • Return the maximum sum among all such subarrays.

Example

Input:

nums = [1,4,2,10,2,3,1,0,20], k = 4

Output:

24
