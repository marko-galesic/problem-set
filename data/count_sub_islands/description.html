Return the number of islands in grid2 that are fully contained within islands in grid1.

Method Signature

public int countSubIslands(int[][] grid1, int[][] grid2)

Requirements

  • Islands are connected 4-directionally.
  • An island in grid2 is a sub-island if every land cell maps to land in grid1.

Example

Input:

grid1 = [[1, 1, 1], [1, 1, 0], [0, 1, 0]], grid2 = [[1, 1, 1], [0, 1, 0], [0, 1, 0]]

Output:

1
