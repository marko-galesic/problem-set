Given an m x n grid of characters board and a string word, return true if word exists in the grid.

Method Signature

public boolean exist(char[][] board, String word)

Requirements

  • The word is formed by sequentially adjacent cells (up, down, left, right)
  • Each cell may be used at most once in the path
  • Return true if the word can be formed, otherwise false

Example

Input:

board = [
  ['A','B','C','E'],
  ['S','F','C','S'],
  ['A','D','E','E']
]
word = "ABCCED"

Output:

true

Explanation: The path A -> B -> C -> C -> E -> D is adjacent and uses each cell once.

Additional Example

Input: board = [
  ['A','B','C','E'],
  ['S','F','C','S'],
  ['A','D','E','E']
]
word = "ABCB"
Output: false

Notes

  • m == board.length
  • n == board[i].length
  • Characters can repeat, but a single cell cannot be reused in a path
