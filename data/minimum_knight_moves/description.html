On an n x n chessboard, return the minimum number of knight moves needed to get from start to end.

Method Signature

public int minKnightMoves(int n, int[] start, int[] end)

Requirements

  • Use standard knight moves (8 possible offsets).
  • Positions are 0-indexed [row, col].
  • Return -1 if the target is unreachable.

Example

Input:

n = 8, start = [0,0], end = [1,2]

Output:

1
