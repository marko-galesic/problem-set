Given a string s, return the string after replacing every uppercase letter with the same lowercase letter. All non-letter characters should remain unchanged.

Method Signature

public String toLowerCase(String s)

Requirements

  • Return a new string with all uppercase letters converted to lowercase
  • Preserve non-letter characters such as digits and punctuation
  • The input string may be empty

Example

Input:

s = "Hello"

Output:

"hello"

Additional Examples

Example 2:

Input: s = "LOVELY"
Output: "lovely"

Example 3:

Input: s = "al&phaBET"
Output: "al&phabet"

Notes

  • You may use built-in string utilities
  • Non-letter characters are not modified
