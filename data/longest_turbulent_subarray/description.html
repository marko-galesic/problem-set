Return the length of the longest turbulent subarray where comparisons alternate.

Method Signature

public int maxTurbulenceSize(int[] arr)

Requirements

  • A subarray is turbulent if the comparisons between adjacent elements alternate.
  • Return 1 for arrays with fewer than 2 elements.

Example

Input:

arr = [9, 4, 2, 10, 7, 8, 8, 1, 9]

Output:

5
