Given an undirected graph, return the number of connected components.

Method Signature

public int countComponents(int n, int[][] edges)

Requirements

  • Nodes are labeled 0..n-1.
  • Edges are undirected pairs.
  • Return 0 if n is 0.

Example

Input:

n = 5, edges = [[0,1],[1,2],[3,4]]

Output:

2
