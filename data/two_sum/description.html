Implement a function twoSum that finds two numbers in an array that add up to a target value and returns their indices.

Method Signature

public int[] twoSum(int[] nums, int target)

Requirements

  • Given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target
  • You may assume that each input would have exactly one solution
  • You may not use the same element twice
  • You can return the answer in any order
  • Return an array containing the two indices: [i, j] where nums[i] + nums[j] == target

Example

Input:

nums = [2, 7, 11, 15]
target = 9

Output:

[0, 1]

Explanation: Because nums[0] + nums[1] = 2 + 7 = 9, we return [0, 1].

Additional Examples

Example 2:

Input: nums = [3, 2, 4], target = 6
Output: [1, 2]

Example 3:

Input: nums = [3, 3], target = 6
Output: [0, 1]

Notes

  • The array may contain negative numbers
  • The array may contain duplicate values
  • There is exactly one valid answer for each test case
  • Indices are 0-based
