Given an integer array nums, find the contiguous subarray that has the largest sum and return the sum.

A subarray is a contiguous part of the array and must contain at least one element.

Method Signature

public int maxSubArray(int[] nums)

Requirements

  • Return the maximum possible sum of any contiguous subarray
  • The subarray must include at least one element
  • The array may contain negative numbers

Example 1

Input:

nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]

Output:

6

Explanation: The subarray [4, -1, 2, 1] has the largest sum.

Example 2

Input:

nums = [1]

Output:

1

Example 3

Input:

nums = [-1, -2, -3]

Output:

-1
