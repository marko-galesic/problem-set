For each element in nums1, find its next greater element in nums2. The next greater element is the first greater number to its right in nums2. If none exists, return -1.

Method Signature

public int[] nextGreaterElement(int[] nums1, int[] nums2)

Example

nums1 = [4,1,2]
nums2 = [1,3,4,2]
Output: [-1,3,-1]
