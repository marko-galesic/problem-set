Implement a function majorityElement that returns the element that appears more than n / 2 times in the array.

Method Signature

public int majorityElement(int[] nums)

Requirements

  • Input array nums is non-empty.
  • A majority element always exists.
  • Return the value of the majority element.

Example

Input:

nums = [3, 2, 3]

Output:

3

Additional Examples

Example 2:

Input: nums = [2, 2, 1, 1, 1, 2, 2]
Output: 2

Example 3:

Input: nums = [-1, -1, -1, 2, 2]
Output: -1

Notes

  • The majority element appears more than half the time.
  • The array may contain negative numbers.
