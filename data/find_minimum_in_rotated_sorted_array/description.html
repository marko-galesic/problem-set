You are given a rotated sorted array of unique integers nums. The array was originally sorted in ascending order and then rotated at an unknown pivot. Return the minimum element.

Method Signature

public int findMin(int[] nums)

Requirements

  • 1 <= nums.length
  • The original array is sorted in ascending order and rotated between 0 and nums.length - 1 times
  • All values are unique
  • Use a logarithmic-time search if possible

Example 1

Input:

nums = [3, 4, 5, 1, 2]

Output:

1

Example 2

Input:

nums = [4, 5, 6, 7, 0, 1, 2]

Output:

0

Example 3

Input:

nums = [11, 13, 15, 17]

Output:

11

Notes

  • The array may not be rotated (pivot at index 0)
  • The array length can be as small as 1
