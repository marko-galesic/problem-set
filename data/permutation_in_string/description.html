Given two strings s1 and s2, return true if s2 contains a permutation of s1, or false otherwise. A permutation of a string is a rearrangement of its characters.

Method Signature

public boolean checkInclusion(String s1, String s2)

Requirements

  • Return true if some substring of s2 is a permutation of s1
  • Return false otherwise
  • If s1 is longer than s2, the result is false
  • You may assume s1 and s2 contain only lowercase English letters

Example

Input:

s1 = "ab", s2 = "eidbaooo"

Output:

true

Explanation: "ba" is a permutation of "ab" and is a substring of s2.

Additional Example

Input: s1 = "ab", s2 = "eidboaoo"
Output: false
