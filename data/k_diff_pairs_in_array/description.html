Given an integer array nums and an integer k, return the number of unique k-diff pairs.

Method Signature

public int findPairs(int[] nums, int k)

Requirements

  • A k-diff pair is (a, b) where |a - b| = k.
  • Count each unique value pair once.

Example

Input:

nums = [3, 1, 4, 1, 5], k = 2

Output:

2
