Implement a function isAnagram that determines whether two strings are anagrams of each other.

Method Signature

public boolean isAnagram(String s, String t)

Requirements

  • Return true if t contains the same characters as s with the same counts
  • Order of characters does not matter
  • Return false otherwise

Example

Input:

s = "anagram"
t = "nagaram"

Output:

true

Explanation: Both strings contain the same letters in a different order.

Additional Examples

Example 2:

Input: s = "rat", t = "car"
Output: false

Example 3:

Input: s = "", t = ""
Output: true

Notes

  • Comparisons are case-sensitive
  • Strings may be empty
