Implement canAttendMeetings to determine if a person can attend all meetings given a list of time intervals.

Method Signature

public boolean canAttendMeetings(int[][] intervals)

Requirements

  • Each interval is [start, end] with start < end
  • Return true if no meetings overlap
  • Return false if any meetings overlap

Example

Input:

intervals = [[0, 30], [5, 10], [15, 20]]

Output:

false

Explanation: The meeting [0, 30] overlaps [5, 10] and [15, 20].

Additional Examples

Example 2:

Input: intervals = [[5, 8], [9, 15]]
Output: true

Example 3:

Input: intervals = []
Output: true

Notes

  • Intervals may be unsorted
  • Touching endpoints (e.g., [1, 2] and [2, 3]) do not overlap
