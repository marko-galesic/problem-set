Given an array of integers, return an array where each element is the product of all other elements.

Method Signature

public int[] arrayProductExceptSelf(int[] nums)

Requirements

  • Return an array where result[i] is the product of all other elements.
  • Do not use division.

Example

Input:

nums = [1, 2, 3, 4]

Output:

[24, 12, 8, 6]
