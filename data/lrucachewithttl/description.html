Implement an LRUCache class with Time-To-Live (TTL) support. The cache should implement a Least Recently Used (LRU) eviction policy, where entries expire after a specified time period.

Class Signature

class LRUCache {
    public LRUCache(int capacity)
    public int get(int key)
    public void put(int key, int value)
}

Requirements

  • LRU Eviction: When the cache reaches capacity, evict the least recently used entry
  • TTL Expiration: Each entry has a time-to-live. Expired entries return -1 and are removed lazily
  • Refresh-on-Write: When updating an existing key with put(), the TTL is refreshed
  • No Refresh-on-Read: Calling get() does NOT refresh the TTL (entries expire based on when they were last written)
  • Return Values: get() returns the value if found and not expired, otherwise returns -1
  • Capacity Handling: If capacity is 0, the cache should not store any entries

TTL Behavior

  • TTL is applied as "expireAt = now + ttlMillis" on every put() operation
  • Expired entries are removed lazily (when accessed via get() or during put() operations)
  • Eviction policy considers only currently stored (non-expired) entries
  • You may hardcode a TTL value (e.g., 5 minutes) or make it configurable via constructor

Example

Basic Usage:

LRUCache cache = new LRUCache(2);
cache.put(1, 1);  // cache = {1: 1}
cache.put(2, 2);  // cache = {1: 1, 2: 2}
cache.get(1);     // returns 1, cache = {2: 2, 1: 1} (1 moved to MRU)
cache.put(3, 3);  // evicts 2 (LRU), cache = {1: 1, 3: 3}
cache.get(2);     // returns -1 (not found)
cache.get(1);     // returns 1
cache.get(3);     // returns 3

TTL Example:

LRUCache cache = new LRUCache(2);
// Assuming TTL is 50ms
cache.put(1, 1);  // at t=0, entry expires at t=50
cache.get(1);     // at t=49, returns 1 (not expired)
cache.get(1);     // at t=50, returns -1 (expired)
cache.put(1, 9);  // at t=40, refresh TTL, expires at t=90
cache.get(1);     // at t=80, returns 9 (not expired)
cache.get(1);     // at t=90, returns -1 (expired)

Notes

  • You can use System.currentTimeMillis() to get the current time
  • Use a doubly-linked list and HashMap for O(1) operations
  • Handle edge cases: capacity=0, negative keys/values, expired entries during eviction
  • For TTL, you may hardcode a value or accept it as a constructor parameter
