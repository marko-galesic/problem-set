Given two strings s1 and s2 of equal length, each pair of characters s1[i] and s2[i] are equivalent. For each character in baseStr, replace it with the smallest equivalent character and return the resulting string.

Method Signature

public String smallestEquivalentString(String s1, String s2, String baseStr)

Example

s1 = "parker"
s2 = "morris"
baseStr = "parser"
Output: "makkek"
