Given an array containing only 0s, 1s, and 2s, return the array sorted in-place by color order (0, then 1, then 2).

Method Signature

public int[] sortColors(int[] nums)

Requirements

  • Return the sorted array
  • Values are only 0, 1, or 2

Example

Input:

nums = [2, 0, 2, 1, 1, 0]

Output:

[0, 0, 1, 1, 2, 2]
