Given a 9x9 Sudoku board filled with digits '1'-'9' and '.' for empty cells, return true if the board is valid.

Method Signature

public boolean isValidSudoku(char[][] board)

Rules

  • Each row must contain the digits 1-9 without repetition
  • Each column must contain the digits 1-9 without repetition
  • Each 3x3 sub-box must contain the digits 1-9 without repetition
  • Empty cells are represented by '.' and should be ignored

Example

Input:

board = [
  ['5','3','.','.','7','.','.','.','.'],
  ['6','.','.','1','9','5','.','.','.'],
  ['.','9','8','.','.','.','.','6','.'],
  ['8','.','.','.','6','.','.','.','3'],
  ['4','.','.','8','.','3','.','.','1'],
  ['7','.','.','.','2','.','.','.','6'],
  ['.','6','.','.','.','.','2','8','.'],
  ['.','.','.','4','1','9','.','.','5'],
  ['.','.','.','.','8','.','.','7','9']
]

Output:

true

Additional Example

Input: board = [
  ['8','3','.','.','7','.','.','.','.'],

  ['.','9','8','.','.','.','.','6','.'],

Notes

  • The board is 9x9
  • A valid board may be incomplete
