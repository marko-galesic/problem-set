Given an undirected unweighted graph, return the length of the shortest path between start and end.

Method Signature

public int shortestPath(int n, int[][] edges, int start, int end)

Requirements

  • Nodes are labeled from 0 to n-1.
  • Edges are undirected pairs.
  • Return -1 if no path exists.

Example

Input:

n = 5, edges = [[0,1],[1,2],[2,3],[3,4]], start = 0, end = 4

Output:

4
