Given a binary matrix, return the shortest path length from the top-left to the bottom-right using 4-directional moves.

Method Signature

public int shortestPathBinaryMatrix4Dir(int[][] grid)

Requirements

  • Cells with value 1 are blocked.
  • Move only up, down, left, or right.
  • Return -1 if no path exists.

Example

Input:

grid = [[0,1],[0,0]]

Output:

2
