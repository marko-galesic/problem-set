Given an integer n, generate an n x n matrix filled with numbers from 1 to n^2 in spiral order.

Method Signature

public int[][] generateMatrix(int n)

Requirements

  • Fill the matrix in clockwise spiral order
  • Values should range from 1 to n^2

Example

Input:

n = 3

Output:

[[1, 2, 3], [8, 9, 4], [7, 6, 5]]
