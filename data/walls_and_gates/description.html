You are given a grid of rooms where -1 is a wall, 0 is a gate, and 2147483647 is an empty room. Fill each empty room with the distance to its nearest gate.

Method Signature

public int[][] wallsAndGates(int[][] rooms)

Requirements

  • Move only up, down, left, or right.
  • Walls remain -1 and gates remain 0.
  • Return the updated grid.

Example

Input:

rooms = [[2147483647,-1,0,2147483647],[2147483647,2147483647,2147483647,-1],[2147483647,-1,2147483647,-1],[0,-1,2147483647,2147483647]]

Output:

[[3, -1, 0, 1], [2, 2, 1, -1], [1, -1, 2, -1], [0, -1, 3, 4]]
