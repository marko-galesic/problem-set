Implement a function removeNthFromEnd that removes the nth node from the end of a singly linked list and returns the head of the modified list.

Method Signature

public ListNode removeNthFromEnd(ListNode head, int n)

Requirements

  • Remove exactly one node: the nth node from the end of the list
  • Return the head of the list after removal
  • The ListNode class is provided as a utility class (see ListNode.java)
  • If the list has a single node and n = 1, return null

ListNode Structure

class ListNode {
    int val;
    ListNode next;

    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}

Example

Input:

head = [1, 2, 3, 4, 5], n = 2

Output:

[1, 2, 3, 5]

Explanation: The 2nd node from the end is 4, so it is removed.

Additional Examples

Example 2:

Input: head = [1], n = 1
Output: []

Example 3:

Input: head = [1, 2], n = 1
Output: [1]

Example 4:

Input: head = [1, 2, 3], n = 3
Output: [2, 3]

Notes

  • The number of nodes is in the range [1, 1000]
  • 1 <= n <= number of nodes
  • Node values are in the range [-1000, 1000]
  • Try to solve it in O(n) time and O(1) extra space
