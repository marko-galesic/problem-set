You are given access to a paginated articles API. Each page contains a list of articles with an author, title, and comment count. Your task is to compute two statistics across all pages by fetching every page from the API.

Method Signature

public Map<String, Integer> analyzeArticles(String author, String title)

Input

  • Each article contains:
    • id: integer ID
    • title: article title
    • author: author name
    • num_comments: number of comments
  • author: author name to match (case-sensitive)
  • title: title to match (case-sensitive)

API

  • Base URL: https://example.com/articles
  • Query param: page (1-indexed)
  • Response JSON shape:
{
  "page": 1,
  "total_pages": 2,
  "data": [
    { "id": 1, "title": "Intro to HTTP", "author": "alice", "num_comments": 5 }
  ]
}

Use requests.get with a params dict (for example, requests.get(BASE_URL, params={"page": 1})) and keep requesting pages until you have processed total_pages.

Output

Return an object/map with exactly two keys:

  • sumByAuthor: the sum of num_comments for all articles by author
  • countTitleMatches: the number of articles with title

Example

# Example responses for pages 1..2 fetched from the API:
page1 = { page: 1, total_pages: 2, data: [
    { id: 1, title: "Intro to HTTP", author: "alice", num_comments: 5 },
    { id: 2, title: "Pagination Tips", author: "bob", num_comments: 3 }
]}
page2 = { page: 2, total_pages: 2, data: [
    { id: 3, title: "Intro to HTTP", author: "alice", num_comments: 2 }
]}
author = "alice"
title = "Intro to HTTP"

Output: { sumByAuthor: 7, countTitleMatches: 2 }

Notes

  • Match author and title using exact, case-sensitive comparison.
  • If there are no matches, the corresponding value should be 0.
  • Use requests.get directly (do not use from requests import get).
