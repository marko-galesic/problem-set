Given a binary matrix, return the length of the shortest clear path from the top-left to the bottom-right, moving in 8 directions. Return -1 if no path exists.

Method Signature

public int shortestPathBinaryMatrix(int[][] grid)

Requirements

  • You may move in 8 directions
  • Cells with value 1 are blocked
  • Return -1 if no valid path exists

Example

Input:

grid = [[0, 1], [1, 0]]

Output:

2
