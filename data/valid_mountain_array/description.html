Given an integer array arr, return true if it is a valid mountain array.

Method Signature

public boolean validMountainArray(int[] arr)

Requirements

  • The array length must be at least 3
  • There is an index i with 0 < i < arr.length - 1 such that:
  • arr[0] < arr[1] < ... < arr[i] (strictly increasing)
  • arr[i] > arr[i + 1] > ... > arr[arr.length - 1] (strictly decreasing)
  • No plateaus are allowed (adjacent elements cannot be equal)

Example

Input:

arr = [0, 3, 2, 1]

Output:

true

Additional Examples

Example 2:

Input: arr = [3, 5, 5]
Output: false

Example 3:

Input: arr = [1, 2, 3, 4, 5]
Output: false

Notes

  • The peak cannot be the first or last element
  • Both sides of the peak must be strictly monotonic
