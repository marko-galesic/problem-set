Given an adjacency list, determine if the graph is bipartite.

Method Signature

public boolean isBipartite(int[][] graph)

Requirements

  • Graph may be disconnected.
  • Use two colors with no adjacent nodes sharing a color.
  • Return true if bipartite, otherwise false.

Example

Input:

graph = [[1,3],[0,2],[1,3],[0,2]]

Output:

true
