Given strings s and t, return the shortest substring of s that contains every character from t (including multiplicity). If there is no such substring, return an empty string.

Method Signature

public String minWindow(String s, String t)

Requirements

  • Return the smallest window in s that contains all characters from t
  • Character counts matter (if t has two of a character, the window must have two)
  • Return "" if no window exists or if t is empty

Example

Input:

s = "ADOBECODEBANC", t = "ABC"

Output:

"BANC"

Explanation: The substring "BANC" is the shortest window containing A, B, and C.

Additional Example

Input: s = "a", t = "aa"
Output: ""
