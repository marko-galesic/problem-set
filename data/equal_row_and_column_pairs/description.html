Given an n x n matrix, return the number of pairs (row, column) that are identical.

Method Signature

public int equalPairs(int[][] grid)

Requirements

  • Rows and columns are compared element by element.
  • Return the total number of matching pairs.

Example

Input:

grid = [[3, 2, 1], [1, 7, 6], [2, 7, 7]]

Output:

1
