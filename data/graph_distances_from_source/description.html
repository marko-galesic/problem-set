Given an undirected unweighted graph, return the distances from the source node to every node.

Method Signature

public int[] distancesFromSource(int n, int[][] edges, int source)

Requirements

  • Nodes are labeled 0..n-1.
  • Edges are undirected pairs.
  • Return -1 for unreachable nodes.

Example

Input:

n = 5, edges = [[0,1],[1,2],[2,3],[3,4]], source = 0

Output:

[0, 1, 2, 3, 4]
