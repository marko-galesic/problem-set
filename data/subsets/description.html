Implement a function subsets that returns all subsets (the power set) of a set of distinct integers.

Method Signature

public int[][] subsets(int[] nums)

Requirements

  • Each subset must list its elements in ascending order
  • The list of subsets must be sorted lexicographically by their elements
  • If one subset is a prefix of another, the shorter subset comes first
  • Include the empty subset

Example

Input:

nums = [1, 2, 3]

Output:

[[], [1], [1, 2], [1, 2, 3], [1, 3], [2], [2, 3], [3]]

Explanation: Each subset is sorted, and the list of subsets is lexicographically ordered.

Additional Example

Input: nums = [3, 1, 2]
Output: [[], [1], [1, 2], [1, 2, 3], [1, 3], [2], [2, 3], [3]]

Notes

  • The input array contains distinct integers
  • There are 2^n subsets for an input of length n
