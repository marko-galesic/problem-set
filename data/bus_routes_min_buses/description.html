Given bus routes and a source/target stop, return the minimum number of buses needed to reach the target.

Method Signature

public int numBusesToDestination(int[][] routes, int source, int target)

Requirements

  • You can transfer between routes at shared stops.
  • Each bus ride counts as 1 toward the answer.
  • Return -1 if the target is unreachable.

Example

Input:

routes = [[1,2,7],[3,6,7]], source = 1, target = 6

Output:

2
