From the start index, you can jump left or right by arr[i]. Return the minimum number of jumps to reach a value of 0.

Method Signature

public int minStepsToReachZero(int[] arr, int start)

Requirements

  • You may jump to i + arr[i] or i - arr[i].
  • Return 0 if arr[start] is 0.
  • Return -1 if no index with value 0 is reachable.

Example

Input:

arr = [4,2,3,0,3,1,2], start = 5

Output:

3
