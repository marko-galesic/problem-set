Given a list of words, answer queries that ask for the highest index of a word with a given prefix and suffix.

Method Signature

public int[] prefixSuffixSearch(String[] words, String[] queries)

Query Format

  • Each query is encoded as "prefix|suffix"
  • Use an empty prefix or suffix by leaving the side empty (e.g. "pre|")

Return Value

  • For each query, return the largest index of a word that starts with the prefix and ends with the suffix
  • Return -1 if no word matches

Example

words = ["apple","apply","ape","apex"]
queries = ["ap|le","ap|ly","a|x","ap|"]

Output: [0,1,3,3]

Notes

  • Words and queries use lowercase English letters
  • The delimiter '|' will not appear in words
