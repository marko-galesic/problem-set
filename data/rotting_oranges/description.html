You are given an m x n grid where each cell can be:

  • 0 = empty
  • 1 = fresh orange
  • 2 = rotten orange

Every minute, any fresh orange that is 4-directionally adjacent to a rotten orange becomes rotten. Return the minimum number of minutes that must elapse until no cell has a fresh orange. If this is impossible, return -1.

Method Signature

public int orangesRotting(int[][] grid)

Requirements

  • Rot spreads only up, down, left, and right (not diagonally)
  • Return 0 if there are no fresh oranges initially
  • Return -1 if some fresh oranges can never rot

Example

Input:

grid = [[2,1,1],[1,1,0],[0,1,1]]

Output:

4

Additional Examples

Example 2:

Input: grid = [[2,1,1],[0,1,1],[1,0,1]]
Output: -1

Example 3:

Input: grid = [[0,2]]
Output: 0

Notes

  • The input grid may be empty
  • Time is measured in whole minutes
