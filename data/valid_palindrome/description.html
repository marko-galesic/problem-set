Given a string s, determine if it is a palindrome after converting all letters to lowercase and removing all non-alphanumeric characters.

Method Signature

public boolean isPalindrome(String s)

Requirements

  • Ignore non-alphanumeric characters
  • Compare letters case-insensitively
  • Return true if the cleaned string reads the same forward and backward
  • The input string may be empty

Example

Input:

s = "A man, a plan, a canal: Panama"

Output:

true

Additional Examples

Example 2:

Input: s = "race a car"
Output: false

Example 3:

Input: s = " "
Output: true

Notes

  • You may use built-in character helpers
  • Only letters and digits are considered
