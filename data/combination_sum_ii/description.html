Given an integer array candidates and an integer target, return all unique combinations of candidates where the chosen numbers sum to target.

Method Signature

public int[][] combinationSum2(int[] candidates, int target)

Requirements

  • Each candidate may be used at most once in a combination
  • Each combination must be sorted in non-decreasing order
  • The list of combinations must be sorted lexicographically
  • No duplicate combinations are allowed
  • Return an empty list when no valid combination exists

Example

Input:

candidates = [10, 1, 2, 7, 6, 1, 5]
target = 8

Output:

[[1, 1, 6], [1, 2, 5], [1, 7], [2, 6]]

Explanation: Each combination is unique, sorted, and ordered lexicographically.

Notes

  • The array may contain duplicate values
  • Each candidate can be used at most once
