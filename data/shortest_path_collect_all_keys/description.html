Given a grid with walls, keys, and locks, return the minimum steps required to collect all keys.

Method Signature

public int shortestPathAllKeys(char[][] grid)

Requirements

  • Move only up, down, left, or right.
  • Locks (A-F) require the corresponding key (a-f).
  • Return -1 if all keys cannot be collected.

Example

Input:

grid = [["@",".","a",".","#"],["#","#","#",".","#"],["b",".",".",".","."]]

Output:

8
