Given an integer array nums, return an array answer where answer[i] is the product of all the elements of nums except nums[i].

Method Signature

public int[] productExceptSelf(int[] nums)

Requirements

  • Return an array of the same length as nums
  • answer[i] equals the product of all elements in nums except nums[i]
  • Do not use division

Constraints

  • 2 <= nums.length <= 100000
  • -30 <= nums[i] <= 30
  • The product of any prefix or suffix of nums fits in a 32-bit integer

Example 1

Input:

nums = [1, 2, 3, 4]

Output:

[24, 12, 8, 6]

Explanation: Each output value is the product of all the other numbers.

Example 2

Input:

nums = [-1, 1, 0, -3, 3]

Output:

[0, 0, 9, 0, 0]
