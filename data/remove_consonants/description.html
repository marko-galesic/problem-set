Given a string s, return s with all consonant letters removed.

Method Signature

public String removeConsonants(String s)

Requirements

  • Consonants are letters a-z that are not vowels (a, e, i, o, u), case-insensitive.
  • Preserve vowels and non-letter characters.
  • The input may be empty.

Example

Input:

s = "Hello"

Output:

"eo"
