Given a matrix with rows and columns sorted in ascending order, return true if target exists in the matrix.

Method Signature

public boolean searchMatrix(int[][] matrix, int target)

Requirements

  • Each row is sorted left to right
  • Each column is sorted top to bottom
  • Return true if the target is found

Example

Input:

matrix = [[1, 4, 7, 11], [2, 5, 8, 12], [3, 6, 9, 16], [10, 13, 14, 17]], target = 5

Output:

true
