Implement a function containsDuplicate that checks whether any value appears at least twice in an array.

Method Signature

public boolean containsDuplicate(int[] nums)

Requirements

  • Return true if any integer appears more than once
  • Return false if all values are distinct

Example

Input:

nums = [1, 2, 3, 1]

Output:

true

Explanation: The value 1 appears twice.

Additional Examples

Example 2:

Input: nums = [1, 2, 3, 4]
Output: false

Example 3:

Input: nums = []
Output: false

Notes

  • The array may be empty
  • Values may be negative or repeated
