Given an integer array nums and an integer k, return the total number of contiguous subarrays whose sum equals k.

Method Signature

public int subarraySum(int[] nums, int k)

Requirements

  • Subarrays must be contiguous
  • Handle negative numbers and zero values
  • Return the count of valid subarrays

Example

Input:

nums = [1, 1, 1], k = 2

Output:

2

Explanation: The subarrays [1, 1] at indices (0,1) and (1,2) both sum to 2.
