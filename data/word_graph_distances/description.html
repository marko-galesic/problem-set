Given a list of words, treat words with one-letter differences as connected and return distances from the start word for each word in order.

Method Signature

public int[] wordGraphDistances(String[] words, String start)

Requirements

  • Words are connected if they have the same length and differ by exactly one character.
  • Return -1 for words that are unreachable.
  • If the start word is not in the list, return all -1.

Example

Input:

words = ["hot","dot","dog","lot"], start = "hot"

Output:

[0, 1, 2, 1]
