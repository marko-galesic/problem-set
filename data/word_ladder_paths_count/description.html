Return the number of shortest transformation sequences from beginWord to endWord, changing one letter at a time using words from the list.

Method Signature

public int ladderPathCount(String beginWord, String endWord, String[] wordList)

Requirements

  • Each step changes exactly one letter.
  • All intermediate words must be in wordList.
  • Return 0 if no sequence exists.

Example

Input:

beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log","cog"]

Output:

2
