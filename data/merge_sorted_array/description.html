Given two sorted arrays, where only the first m elements of nums1 and the first n elements of nums2 are valid, return a new sorted array of length m + n.

Method Signature

public int[] mergeSortedArray(int[] nums1, int m, int[] nums2, int n)

Example

Input:

nums1 = [1, 2, 3, 0, 0, 0], m = 3
nums2 = [2, 5, 6], n = 3

Output:

[1, 2, 2, 3, 5, 6]
