Given an integer array nums and an integer k, return an array of the maximum value in each contiguous subarray (sliding window) of size k.

The result should contain nums.length - k + 1 values, one per window.

Method Signature

public int[] maxSlidingWindow(int[] nums, int k)

Requirements

  • 1 <= k <= nums.length
  • nums contains integers (positive, negative, or zero)
  • Return the maximum for each window in order from left to right

Example 1

Input:

nums = [1, 3, -1, -3, 5, 3, 6, 7], k = 3

Output:

[3, 3, 5, 5, 6, 7]

Explanation: The window maximums are 3, 3, 5, 5, 6, 7.

Example 2

Input:

nums = [4, 2, 12], k = 1

Output:

[4, 2, 12]

Notes

  • Use a sliding window with a monotonic deque for an O(n) solution
