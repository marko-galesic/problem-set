Given a square matrix, return the minimum sum of a falling path from top to bottom.

Method Signature

public int minFallingPathSum(int[][] matrix)

Requirements

  • From each cell, you may move down, down-left, or down-right.
  • Return the minimum possible sum.

Example

Input:

matrix = [[2, 1, 3], [6, 5, 4], [7, 8, 9]]

Output:

13
