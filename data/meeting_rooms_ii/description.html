You are given an array of meeting time intervals where intervals[i] = [start, end]. Return the minimum number of conference rooms required to host all meetings.

Method Signature

public int minMeetingRooms(int[][] intervals)

Requirements

  • Each interval has start < end
  • If one meeting ends at time t, another can start at t without overlapping
  • Return 0 when there are no meetings

Example

Input:

intervals = [[0,30],[5,10],[15,20]]

Output:

2

Additional Examples

Example 2:

Input: intervals = [[7,10],[2,4]]
Output: 1

Example 3:

Input: intervals = []
Output: 0
