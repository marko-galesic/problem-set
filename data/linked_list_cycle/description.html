Implement a function hasCycle that determines whether a singly linked list contains a cycle.

Method Signature

public boolean hasCycle(ListNode head)

Requirements

  • Return true if the linked list has a cycle, otherwise return false
  • A cycle exists if a node can be reached again by continuously following next
  • The ListNode class is provided as a utility class (see ListNode.java)
  • If the input list is empty (null), return false

ListNode Structure

class ListNode {
    int val;
    ListNode next;

    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}

Example

Input:

head = [3, 2, 0, -4], pos = 1

Output:

true

Explanation: The tail connects to the node at index 1, forming a cycle.

Additional Examples

Example 2:

Input: head = [1, 2], pos = 0
Output: true

Example 3:

Input: head = [1], pos = -1
Output: false

Notes

  • The number of nodes is in the range [0, 10^4]
  • Node values are in the range [-10^5, 10^5]
  • The pos value indicates the zero-based index that the tail connects to; -1 means no cycle
  • Try to solve it in O(n) time and O(1) extra space
