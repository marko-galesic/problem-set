Given an integer array nums and an integer k, find the maximum average value of any contiguous subarray of length k.

Return the maximum average.

Method Signature

public double findMaxAverage(int[] nums, int k)

Requirements

  • 1 <= k <= nums.length
  • nums contains integers (positive, negative, or zero)
  • Return a floating-point value representing the maximum average

Example 1

Input:

nums = [1, 12, -5, -6, 50, 3], k = 4

Output:

12.75

Explanation: The subarray [12, -5, -6, 50] has the maximum average of 12.75.

Example 2

Input:

nums = [5], k = 1

Output:

5.0

Notes

  • The array length can be as small as 1
  • Use a sliding window to compute averages efficiently
