Given a grid with start "*", food "#", obstacles "X", and open cells "O", return the minimum steps to reach any food cell.

Method Signature

public int shortestPathToFood(char[][] grid)

Requirements

  • Move only up, down, left, or right.
  • You may not move through obstacles.
  • Return -1 if no food is reachable.

Example

Input:

grid = [["X","X","X","X","X","X"],["X","*","O","O","O","X"],["X","O","O","#","O","X"],["X","X","X","X","X","X"]]

Output:

3
