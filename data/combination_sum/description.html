Given a list of positive integers candidates and a target integer target, return all unique combinations of candidates where the chosen numbers sum to target. You may use each candidate value an unlimited number of times.

Method Signature

public int[][] combinationSum(int[] candidates, int target)

Requirements

  • Each combination must be sorted in ascending order
  • The list of combinations must be sorted lexicographically
  • No duplicate combinations are allowed
  • Return an empty list if no combination sums to the target

Example

Input:

candidates = [2, 3, 6, 7]
target = 7

Output:

[[2, 2, 3], [7]]

Explanation: The combinations [2, 2, 3] and [7] sum to 7 and are returned in lexicographic order.

Additional Example

Input: candidates = [2, 3, 5], target = 8
Output: [[2, 2, 2, 2], [2, 3, 3], [3, 5]]

Notes

  • All candidates are positive integers
  • Each candidate can be chosen unlimited times
