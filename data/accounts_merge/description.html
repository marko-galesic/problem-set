Merge accounts that share common email addresses. Each account is provided as a comma-separated string: "Name,email1,email2,...".

Method Signature

public String[][] accountsMerge(String[] accounts)

Input Format

  • accounts[i] is a comma-separated list where the first token is the name
  • Names and emails will not contain commas

Output Format

  • Return merged accounts as arrays: [name, email1, email2, ...]
  • Sort emails within each account lexicographically
  • Sort accounts by name, then by first email

Example

accounts = [
  "John,johnsmith@mail.com,john_newyork@mail.com",
  "John,johnsmith@mail.com,john00@mail.com",
  "Mary,mary@mail.com",
  "John,johnnybravo@mail.com"
]

Output:
[
  ["John","john00@mail.com","john_newyork@mail.com","johnsmith@mail.com"],
  ["John","johnnybravo@mail.com"],
  ["Mary","mary@mail.com"]
]
