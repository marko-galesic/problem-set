Given an array of asteroids moving along a line, return the state of the asteroids after all collisions.

Method Signature

public int[] asteroidCollision(int[] asteroids)

Requirements

  • Positive values move right, negative values move left
  • When two collide, the smaller (by absolute value) explodes

Example

Input:

asteroids = [5, 10, -5]

Output:

[5, 10]
